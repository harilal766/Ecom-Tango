## orders that are send with Indiapost.
If the address is not proper, the chance of returning is higher.
We can't hope the postman will contact the customer in this scenario. 
According to the standards of indiapost, a proper address will have,
1. Recipient's name (with title like Mr./Ms. if applicable).
2. House/flat number, building name, street/road name.
3. Locality/area, landmark (optional but helpful), city/town, district.
4. State and 6-digit PIN code (essential for sorting).
