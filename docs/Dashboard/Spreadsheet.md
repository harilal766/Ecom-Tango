





# Formula Class
This class is used to encapsulate the functions needed to create excel formulas.

## find cell index
To find the index of a cell in spreadsheet, we need to get the alphabet in the column and number of its row.
Any formula will have a starting and ending cell index in common.

**Arguments**
1. Numbers of column and row of the target cell.

**Pseudocode**
1. assign the variables `column_alphabet`, `column_number`, `row_number`. 
2. assign `column_alphabet` with `char(64 + column_number)` function.
3. column index can be generated by the string `f"{column_alphabet}{row_number}"`.


## generate sum formula
Sum formulas are available in horizontal and vertical direction.
1. in horizontal, eg : `=sum(A3:D3)` the row count is static and the column alphabet is dynamic.
2. in vertical, eg: `=sum(A3:A6)` its vice versa.
