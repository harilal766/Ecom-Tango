# Ecom-Tango
Django based web application to automate and centalize the handling of repetitive tasks on multiple Ecommerce seller platforms.Currently working on support for Amazon seller central, Support for Shopify will be addded in the future.

## Available Operations
1. Order Report generation for daily shipment reconciliation, with additional sheets for pivot table and table to tally shipping labels count with report.
